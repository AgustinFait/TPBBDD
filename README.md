# Fábrica de Sillones: base de datos y Business Intelligence

**De una planilla desordenada a una base de datos normalizada y un tablero de indicadores.** TP de Gestión de Datos (UTN-FRBA, 2025), en un equipo de 4.

![SQL Server](https://img.shields.io/badge/SQL%20Server-CC2927?style=flat-square&logo=microsoftsqlserver&logoColor=white)

![Data Warehouse](https://img.shields.io/badge/Data%20Warehouse-555?style=flat-square)

- **Modelo relacional de 24 tablas**, diseñado a partir de una tabla maestra desnormalizada.
- **Migración automática** con 26 procedimientos almacenados, triggers y constraints.
- **Data Warehouse en esquema estrella** (12 tablas) con **10 vistas de KPIs**: ganancias, conversión de pedidos, cumplimiento de envíos y más.
